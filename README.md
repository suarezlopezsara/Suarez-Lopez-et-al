# Suarez-Lopez-et-al
This repository contains the FIji Macros used for image analysis in the paper "Loss of RIN1 decouples dendritic spine structure from synaptic strength and impairs hippocampal long-term depression".

Requirements:
-  Fiji (ImageJ) (v. 1.54f; Java 1.8.0_322 (64-bit) - https://imagej.net/software/fiji/
-  Ilastik (pixel classitfication/auto-context) - https://www.ilastik.org/
  

## Included Macros

1. Dendrite segmentation.ijm
   
Creates a mask for the segmentation of dendrites usign 2 Ilastik string models.
- Input: original .czi files of the dendrites
- Output: a .tif file with 2 channels (dendrite and background) and a .tif sub-stack of the selected z-planes containing the original channels 

2. Surface_GluA1_fluorescence_quantification.ijm
   
Measures GluA1 fluorescence intensity inside the dendrite ROI.
- Input: dendrite segementation mask and sub-stack generated by macro 1
- Output: table with GluA1 fluorescence intensity values

3. GluA1_in_Shank2_positive_areas.ijm
   
Measures GluA1 fluorescence intensity inside a ROI generated from thresholding the Shank2 signal.
- Input: dendrite mask and sub-stack generated by macro 1
- Output: table with GluA1 fluorescence intensity values restricted to Shank2-posotive areas. 

4. Measure_Shank2_in_spine_ROI.ijm
   
Measures the area of Shank2 puncta inside ROIs that delimitate the head of mushroom dendritic spines. Head ROIs are created manually.
- Input: spine ROIs generated after spine classification with the  Dendritic Spine Counter plugin, sub-stack .tif generated by macro 1 (Shank2 channel).
- Output: .zip file with the mushroom spine heads, .zip file and a table with area values for Shank2 puncta
